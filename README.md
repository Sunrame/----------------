# VPNHub — народный каталог VPN

Статический сайт: без бэкенда, без базы. Голоса и отзывы живут в памяти страницы (демо-режим); для реального хранения понадобится API.

## Структура

```
index.html      — главная (каталог + вкладка «О сервисе»)
terms.html      — пользовательское соглашение
privacy.html    — политика конфиденциальности
legal.html      — правовая информация
404.html        — страница ошибки
css/style.css   — все стили
js/app.js       — данные каталога (массив DATA) и вся логика
img/            — логотип и фавиконка (прозрачный фон)
robots.txt, sitemap.xml
Dockerfile, nginx.conf — для деплоя контейнером (Railway / VPS)
```

```bash
grep -rl 'vpnhub.up.railway.app' . | xargs sed -i 's|vpnhub\.up\.railway\.app|мой-домен.ru|g'
```

## Как захостить

**Railway (твой вариант):** новый сервис → Deploy from GitHub repo → Railway сам увидит `Dockerfile` и соберёт nginx-контейнер. Порт подставится автоматически через переменную `PORT`. Домен: Settings → Networking → Generate Domain или свой.

**GitHub Pages / Cloudflare Pages / Netlify:** это чистая статика — просто залей содержимое папки (Dockerfile и nginx.conf им не нужны, не помешают). На Cloudflare Pages бонусом получишь CDN, что для RU-аудитории может быть актуально.

**Свой VPS:** скопируй файлы в `/var/www/vpnhub`, возьми `nginx.conf` за основу (замени `${PORT}` на `80`, добавь `server_name` и TLS через certbot).

**Локальный просмотр:**

```bash
python3 -m http.server 8000
# открой http://localhost:8000
```

## Редактирование каталога

Все сервисы — в массиве `DATA` в начале `js/app.js`. Одна запись:

```js
{n:'Название', upd:'27 июл', u:727, w:98, p:1, x:1, r:4.9, rv:45,
 wl:'ok', pr:199, tr:'Безлимит', dv:'3', pt:['VLESS','Reality'], trl:true}
```

`w/p/x` — голоса (работает/частично/нет), из них считается статус; `wl` — обход белых списков (`ok`/`mid`/`no`); `pr` — цена (0 = бесплатно); `trl` — пробный период.

## Юридическое (важно, прочитай)

Это **не юридическая консультация**, но логика документов такая:

- Сайт позиционирован как **информационно-справочный каталог с пользовательскими оценками** — не реклама. Поэтому в коде **нет платных размещений, промо-меток и партнёрских ссылок** — их появление ломает всю конструкцию: с 01.09.2025 реклама VPN прямо запрещена (штрафы для физлиц 50–80 тыс. ₽, для юрлиц до 500 тыс. ₽).
- Не добавляй формулировки-призывы («качай», «обходи блокировки», «доступ к запрещённым сайтам») — ни в тексты, ни в описания сервисов.
- E-mail для жалоб должен работать: быстрое удаление контента по обращению — твой главный аргумент добросовестности.
- Дисклеймеры снижают риски, но не обнуляют их: тематика в РФ чувствительная, сайт могут заблокировать по критериям «популяризации средств обхода» независимо от оговорок. Если проект серьёзный — покажи документы юристу.
