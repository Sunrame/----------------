# VPNHub — с настоящим бэкендом

Это замена прежней статической версии. Теперь у сайта есть память: FastAPI + PostgreSQL,
голоса и отзывы реально сохраняются от всех посетителей, а заявки и модерация принимаются
через закрытую панель **/admin** — без единого коммита в GitHub.

Полностью протестировано локально на настоящем PostgreSQL перед отправкой: вход,
создание/редактирование/скрытие/удаление сервиса, голосование (в том числе повторное с
того же IP), отзыв с модерацией, голая оценка без текста (публикуется сразу), заявка →
одобрение → сервис, отклонение заявки, выход из админки, отдача статики и 404 — всё
проверено настоящими HTTP-запросами, не только на глаз.

## Структура

```
app/main.py       — точка входа: отдаёт сайт, /api, /admin одним сервисом
app/db.py         — пул PostgreSQL и схема таблиц (создаётся сама при первом старте)
app/security.py   — вход админа (подписанная cookie), хэш IP для антинакрутки
app/api.py        — публичный API: каталог, голос, отзыв, заявка
app/admin.py      — админ API: логин, заявки, модерация отзывов, CRUD сервисов
admin/index.html  — сама панель администратора (один файл)
static/           — прежний сайт как есть (index.html, css/, js/, img/, юрдокументы)
Dockerfile        — Python 3.12 + uvicorn, слушает $PORT
requirements.txt
```

Старые `nginx.conf` и nginx-Dockerfile этой версии не нужны — можно удалить из репозитория,
их место занял этот Dockerfile.

## Деплой на Railway

**1. Добавь PostgreSQL.** В проекте: **+ New → Database → Add PostgreSQL**. Railway создаст
отдельный сервис с базой.

**2. Пропиши переменные приложению.** В сервисе с этим кодом → **Variables** → **New Variable**:

| Переменная | Значение |
|---|---|
| `DATABASE_URL` | нажми **Add Reference** → выбери `Postgres` → `DATABASE_URL` (Railway подставит ссылку на базу сам) |
| `ADMIN_USER` | логин для входа в `/admin`, например `admin` |
| `ADMIN_PASSWORD` | придумай надёжный пароль — без него вход в админку не откроется вообще |
| `SECRET_KEY` | случайная строка для подписи сессии. Пример (сгенерирован для тебя, замени на свой при желании): `huY0X5wO0M0JzpZEPQ-o9ofWYglXzX0feXAyav-f5wk` |
| `PORT` | `8080` |

`SECRET_KEY` — это не пароль, который вводят, а ключ подписи cookie-сессии. Если его
поменять, все, кто сейчас залогинен в админку, просто разлогинятся — данные не пострадают.

**3. Заливай код** — тем же репозиторием, что и раньше, поверх старого содержимого.
Railway увидит новый `Dockerfile` и соберёт Python-образ вместо nginx.

**4. Networking.** В настройках домена (Settings → Networking) выставь target port `8080`
— как и переменную `PORT` выше.

**5. Готово.** Открывай `https://vpnhub.up.railway.app/admin`, входи под `ADMIN_USER` /
`ADMIN_PASSWORD` — и это твой полноценный админ-доступ.

## Как это работает изнутри

- **Голосование анонимное.** Один голос на сервис с одного IP (реального IP самого
  посетителя, который Railway передаёт в заголовке); повторный голос с того же IP
  переписывает прежний, а не плодит дубликаты.
- **Оценка звёздами без текста публикуется сразу** — минимальный риск злоупотребления.
  **Оценка с текстом отзыва уходит на модерацию** — она появится в каталоге и попадёт в
  средний рейтинг только после того, как ты нажмёшь «Опубликовать» во вкладке «Отзывы».
- **Заявка на добавление сервиса** от посетителя падает во вкладку «Заявки». Кнопка
  «Добавить в каталог» открывает готовую форму, предзаполненную из заявки — остаётся
  проверить и сохранить; заявка сама пометится как обработанная.
- **Скрыть ≠ удалить.** Тумблер «Скрыть» прячет сервис из публичного каталога, но не
  трогает его голоса/отзывы — можно вернуть обратно в любой момент. «Удалить» стирает
  сервис вместе со всей историей голосов и отзывов безвозвратно.
- IP посетителей нигде не хранится в открытом виде — только его солёный хэш, этого
  достаточно для защиты от повторного голосования, но не позволяет восстановить сам IP.

## Локальная проверка (если понадобится)

```bash
pip install -r requirements.txt
export DATABASE_URL="postgresql://user:pass@localhost:5432/vpnhub"
export ADMIN_USER=admin ADMIN_PASSWORD=locale123 SECRET_KEY=dev-only PORT=8080
uvicorn app.main:app --host 0.0.0.0 --port 8080
```

Схема базы создаётся автоматически при первом запуске — руками ничего накатывать не нужно.
